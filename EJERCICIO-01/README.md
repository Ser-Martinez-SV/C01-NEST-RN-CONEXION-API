# Ejercicio 01  

## Qué he aprendido
He aprendido que un controlador recibe peticiones y puede responder en distintas rutas.

## Respuesta a la pregunta de comprensión
`@Get()` indica que una ruta responde cuando se hace una petición para obtener información.

## Qué he modificado
He añadido la ruta `GET /hola/id`, que devuelve el mensaje "Endpoint modificado".

## Resultado
`GET /hola` muestra "Hello World!" y `GET /hola/id` muestra "Endpoint modificado".
